## 4. Case Studies in Practice

### Case Study A: Orbital Command (3D WebGL Engine)
* **Human Architectural Choice:** Recognized that rendering 10,000 discrete Three.js meshes causes draw call saturation. Directed the AI to restructure rendering into an `InstancedMesh` with a flattened `Float32Array` transform buffer.
* **Result:** Achieved 60 FPS client-side rendering with $<45\text{ MB}$ memory footprint.

### Case Study B: Math Logic Engine (Symbolic CAS)
* **Human Mathematical Choice:** Formulated recursive tree grammar and LIATE integration heuristics for JEE calculus. Directed the AI to implement the AST visitor pattern and Streamlit interactive proof inspector.
* **Result:** Developed a transparent educational calculus solver with 94.6% benchmark accuracy on entrance exam calculus questions.

### Case Study C: Social News Bridge (Automation Pipeline)
* **Human Systems Choice:** Architected asynchronous polling against Telegram channels, automated video composition with MoviePy, and Meta Graph API publishing with backoff retry logic.
* **Result:** Production pipeline operating autonomously with zero manual intervention.
